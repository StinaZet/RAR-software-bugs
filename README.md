# Known Issues in Open-Source Response-Adaptive Randomization Software

This page tracks bugs and implementation issues identified in open-source
software for response-adaptive randomization (RAR), found during the
preparation of a survey of such software. It is intended as a resource for
users of this software, not as an ongoing audit or certification of any
package.

**Scope.** Entries here reflect issues noticed during review of specific
packages and versions. Absence of an entry for a package does not imply the
package is free of issues, and an open entry does not imply the issue is
still present in the current version — always check the linked issue for the
latest status and consult the package's own changelog or repository.

**Reporting an issue.** If you have found a bug in an RAR software package,
please [open a new issue](../../issues/new/choose) using the "Report a
software issue" template. You do not need to provide a fix or a reproducible
script — a clear description of the problem is enough.

**Status labels.** Each issue is labelled with the affected package and a
status:
- `unconfirmed` — reported, not yet independently verified
- `confirmed` — verified against the package's documentation or source
- `fixed upstream` — resolved in a later release of the package

Filter by label to see all reported issues for a given package.

## Currently tracked packages
